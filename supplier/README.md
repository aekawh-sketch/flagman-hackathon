# Портал поставщика «ФрешПоставка»

Мини-сайт внешней системы: поставщик собирает накладную, и она **по API** уходит в склад ресторана
(Флагман) на приёмку. Портал показывает ровно тот запрос, что ушёл (JSON или XML), ответ склада и —
позже — что ресторан сделал при приёмке: принял, принял частично (сколько и почему) или отклонил.

```bash
npm start            # node --env-file=.env server.js — Node 22, без зависимостей
# http://localhost:3002
```

`.env` (не в git):

```
PORT=3002
FLAGMAN_URL=http://localhost:8080
FLAGMAN_API_KEY=sk_supplier_…        # то же значение — stock.supplier-api-key в flagman/backend/config/application.yml
SUPPLIER_NAME=ООО «ФрешПоставка»
```

## Что показывает

- **Рестораны платформы** — все предприятия Флагмана и их точки (`GET /api/supplier/restaurants`): ключ портала —
  ключ поставщика платформы, поэтому новые предприятия появляются в списке сами (с пометкой «новое», пока их не выбрали).
- **Каталог выбранного ресторана** — поставщик привозит то, что есть у ресторана (`GET /api/{точка}/supply-catalog`).
  У нового предприятия каталог пуст — позиции добавляются как «+ Новый продукт» (название и единица): склад заведёт
  карточку с пометкой «проверить» и покажет её ресторану при приёмке.
- **Накладная**: точка, номер, дата отгрузки (можно задним числом — от неё ресторан считает сроки), позиции
  в кг / л / шт, срок годности, сумма. Подсказка «годен до» и «уже просрочен — ресторан не примет».
- **JSON или XML** — один и тот же документ в двух форматах Флагмана.
- **Отправить ещё раз** — тот же документ: склад отвечает `200` и не задваивает поставку (идемпотентность).
- **Наши отгрузки** — статус приёмки и причины недоприёма по строкам; обновляется каждые 5 секунд.

## Безопасность

- Ключ Флагмана живёт только на сервере портала; браузер ходит к порталу, а не к складу.
- У ключа одно право — `deliveries:create`: прислать поставку на приёмку и посмотреть **свои** поставки (накладные
  других поставщиков и сотрудников ресторана склад ему не показывает). Ключ без предприятия заводит только сервер
  Флагмана по настройке `stock.supplier-api-key` — админ предприятия такой создать не может.
  Принять поставку, списать или поменять каталог по нему нельзя — это делают сотрудники ресторана.
- Поставщик в документе всегда свой (подставляет сервер), статика отдаётся только из `public/`.
