ФЛАГМАН — склад ресторана
Программа для Windows 10 и 11 (64 бита). Ничего ставить не нужно.

ДВА РЕЖИМА — переключаются в меню «Флагман» окна программы
  С сервером (по умолчанию)  склад в интернете — http://31.76.28.248:8085. Тот же, что в телефоне и в браузере:
                             все видят одни данные. Нужен интернет.
                             Сменить адрес — «Флагман → Адрес сервера…».
  Без сервера                свой склад на этом компьютере: база PostgreSQL 16 и Java 25 внутри программы,
                             данные — из присланного дампа и только здесь. Интернет не нужен.
                             Включить — «Флагман → Работать без сервера…»; вернуться — «Подключиться к серверу…».

ЧТО В ПАПКЕ
  Flagman.exe                склад — окно программы. С него и начинать.
  Open-Cafe-Site.bat         сайт кафе ИСТОК для гостей — сразу откроется в браузере
  Open-Cashier.bat           касса кафе (панель ресторана) — вход demo-cashier / demo1234
  Open-Supplier-Portal.bat   портал поставщика: накладная уходит на склад по API
  README.txt                 эта инструкция
  app\                       сама программа — внутрь заходить не нужно
  offline\                   батники режима «без сервера» — свой склад и сайты на этом компьютере
  Open-*.bat открывают сайты на сервере — ничего не запускают и не ищут. Сервер переехал — адреса
  меняются в одном месте: app\tools\addresses.bat.

КАК ЗАПУСТИТЬ
1. Распакуйте архив целиком, лучше в C:\Flagman — путь без русских букв.
   Обновляете программу — сначала удалите старую папку C:\Flagman (данные склада хранятся отдельно и не пропадут).
2. Запустите Flagman.exe.
   Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
   Программа не подписана сертификатом разработчика, для самодельных программ это обычное дело.
3. Программа подключится к складу на сервере. Сервер не ответил — откроется «Подключение к складу»:
   проверьте интернет, смените адрес или нажмите «Работать без сервера».
4. Вход: «Демо-вход» → любая роль. Пароль демо-учёток — demo1234.
   PIN: управляющий 2222, кладовщик 3333, повар 4444, кассир 5555, админ 1111.

РЕЖИМ «БЕЗ СЕРВЕРА»: ГДЕ ДАННЫЕ — C:\ProgramData\Flagman
  Первый запуск в этом режиме — до минуты: программа создаёт базу и загружает в неё данные склада.
  pgdata\          база PostgreSQL (склад и заказы сайта)
  uploads\         фото накладных и списаний
  logs\            журналы: если что-то не запустилось, пришлите эту папку
  db-password.txt  пароль к базе
  keys.env         ключи сайта и портала к складу; ADMIN_TOKEN — служебный пароль панели без логина
  «Вернуть базу к исходной» (меню «Флагман») — откатить склад к присланному состоянию.
  Подключиться к базе (DBeaver, pgAdmin): хост 127.0.0.1, порт 54329, база flagman, пользователь flagman,
  пароль — из db-password.txt. База работает, пока программа открыта или запущен offline\start-db.bat.

ТЕ ЖЕ КОМАНДЫ РУКАМИ (без сервера) — в cmd, из папки программы:
  set DATA=C:\ProgramData\Flagman
  app\resources\runtime\pgsql\bin\pg_ctl.exe start -w -D "%DATA%\pgdata" -l "%DATA%\logs\postgres.log"
  set /p DB_PASSWORD=<"%DATA%\db-password.txt"
  set DB_URL=jdbc:postgresql://127.0.0.1:54329/flagman
  set DB_USER=flagman
  set UPLOADS_DIR=%DATA%\uploads
  set WEB_DIR=%CD%\app\resources\web
  set SERVER_ADDRESS=127.0.0.1
  app\resources\runtime\jre\bin\java.exe -jar app\resources\server\stock.jar
  → открыть http://localhost:8080
  app\resources\runtime\pgsql\bin\pg_ctl.exe stop -D "%DATA%\pgdata"

Дамп базы, из которого программа разворачивает склад без сервера: app\resources\seed\flagman.dump (PostgreSQL 16).
